# SkinScope — ML Backend

This folder adds a **real, trained machine learning model** to your SkinScope
frontend. Here's how the pieces fit together and how to run it.

## How it works (the pipeline)

```
photo (browser)
   │  fetch() POST, multipart/form-data
   ▼
app.py            Flask server, receives the photo
   │
   ▼
features.py       OpenCV turns the photo into 6 numbers
   │               (redness, oiliness, texture, dark_spots, wrinkles, dryness)
   ▼
model.py           loads model.joblib, predicts severity per concern
   │
   ▼
JSON response  →  result.html shows it (via js/result.js)
```

`train.py` is what CREATED `model.joblib` — you already ran it once, and a
trained model is included. You don't need to run it again unless you want to
retrain (e.g. once you have real photos — see the note at the bottom of
`train.py`).

## 1. Install dependencies

```bash
cd ml
pip install -r requirements.txt
```

## 2. Start the ML backend

```bash
python app.py
```

You should see `Running on http://127.0.0.1:5000`. Leave this running.

## 3. Serve the website

Because the frontend now makes a network request (`fetch`) to `localhost:5000`,
opening `diagnose.html` directly as a `file://` URL will fail (browsers block
that for security). Serve the site with a simple local server instead, from
the **project root** (one level up from `ml/`):

```bash
cd ..
python -m http.server 8000
```

Then open **http://localhost:8000/index.html** in your browser.

## 4. Try it

Go to **Diagnose Skin**, upload any face photo, click **Analyze Skin**. It
sends the photo to your Flask server, which runs it through the real model
and redirects you to the Result page with live predictions (score, skin
type, and per-concern severity all come from the model now — nothing is
hardcoded anymore).

## Retraining with real data

Right now `model.joblib` was trained on **synthetic data** (see the big
comment at the top of `train.py`) because no real labeled photos were
available. The model architecture and pipeline are real — only the training
data is synthetic. When you're ready to improve accuracy:

1. Collect/download a real labeled skin dataset (Kaggle has several acne/skin
   type datasets — download it yourself, this sandbox can't reach Kaggle).
2. Edit `train.py`'s `make_synthetic_dataset()` — replace it with code that
   loads your real photos through `features.extract_features()`.
3. Run `python train.py` again — it overwrites `model.joblib`.
4. Restart `app.py`. Nothing else changes.

## Files

| File | Purpose |
|---|---|
| `features.py` | Image → numeric features (OpenCV) |
| `train.py` | Trains the RandomForest models, saves `model.joblib` |
| `model.py` | Loads `model.joblib`, turns features into a result |
| `app.py` | Flask server, exposes `POST /api/analyze` |
| `model.joblib` | The trained model (binary file, generated by `train.py`) |
| `requirements.txt` | Python packages needed |
